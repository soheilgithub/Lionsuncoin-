# 🦁 Lionsun Airdrop Demo

A beautiful, interactive airdrop page for Lionsun Coin with a fantasy-gaming theme and golden/navy-blue color palette.

## ✨ Features

### 🎨 Visual Design
- **Fantasy-gaming theme** with cosmic elements
- **Golden/navy-blue palette** for premium feel
- **Animated background** with stars, sunlight rays, and lion aura
- **Glowing effects** and smooth animations
- **Responsive design** for all devices

### 🚀 Core Functionality
- **Live countdown timer** showing airdrop end time
- **Wallet connection simulation** (MetaMask, WalletConnect, Trust Wallet)
- **Interactive claim system** with loading states
- **Referral system** with copy-to-clipboard functionality
- **Dynamic wallet address generation**
- **URL parameter handling** for referral links

### 🎯 User Experience
- **Smooth animations** and hover effects
- **Particle effects** on button clicks
- **Toast notifications** for user feedback
- **Modal dialogs** for wallet selection
- **Scroll animations** for content reveal

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Grid, Flexbox, and animations
- **Vanilla JavaScript** - Interactive functionality
- **Font Awesome** - Icons
- **Google Fonts** - Orbitron and Inter fonts

## 🚀 Quick Start

1. **Clone or download** the project files
2. **Open `index.html`** in your web browser
3. **Start exploring** the interactive airdrop page!

### Local Development Server

For the best experience, serve the files through a local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

## 🎮 Interactive Features

### Wallet Connection
- Click "Connect Wallet" to open the wallet selection modal
- Choose from MetaMask, WalletConnect, or Trust Wallet
- Simulated connection process with loading states
- Dynamic wallet address generation

### Claim Process
- After connecting wallet, the claim section appears
- Click "Claim Now" to simulate the claiming process
- Loading animation and success feedback
- 150 $LIONSUN reward display

### Referral System
- Automatic referral link generation
- Copy-to-clipboard functionality
- Referral statistics display
- URL parameter handling for incoming referrals

### Countdown Timer
- Real-time countdown to airdrop end
- Updates every second
- Responsive design for mobile devices

## 🎨 Customization

### Colors
The color scheme is defined in CSS custom properties:

```css
:root {
    --primary-gold: #ffd700;
    --secondary-gold: #ffed4e;
    --navy-blue: #1a1a2e;
    --deep-blue: #16213e;
    /* ... more colors */
}
```

### Animations
- Background animations in `styles.css`
- Particle effects in `script.js`
- Scroll animations and hover effects

### Content
- Update text content in `index.html`
- Modify countdown time in `script.js`
- Customize reward amounts and referral bonuses
