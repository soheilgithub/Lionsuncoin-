## 🛠️ TECHNICAL PRODUCTION SPECS

### **Print Production**
```
Resolution: 300 DPI minimum
Color Mode: CMYK + Spot colors for gold effects
Bleed: 0.125" all sides
Safe Area: 0.25" from trim
File Format: PDF/X-1a, AI, or EPS
Paper Stock: Recommendations by use case
```

### **Digital Production**
```
Resolution: 72-144 DPI (device dependent)
Color Mode: RGB
File Formats: PNG (transparency), JPG (solid), SVG (scalable)
Optimization: Compressed for web, full quality for download
Animation: GIF, MP4, or CSS-based
```
