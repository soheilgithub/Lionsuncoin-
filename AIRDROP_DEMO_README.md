# 🌞 Lionsun Airdrop Demo

## Overview

This is a beautiful, responsive airdrop page for Lionsun Coin with a fantasy-gaming theme featuring a golden/navy-blue color palette. The page includes all the features described in your requirements and is ready for demonstration to your team, agents, or investors.

## 🎨 Design Features

### Visual Style
- **Theme**: Fantasy-gaming with cosmic elements
- **Color Palette**: Golden (#FFD700) and Navy Blue (#1a1a3a)
- **Background**: Cosmic gradient with radial glow effects
- **Typography**: Orbitron (headings) and Rajdhani (body text)
- **Effects**: Glowing borders, backdrop blur, smooth animations

### Key Sections

#### 1. Header Section
- 🌞 **LIONSUN AIRDROP LIVE!** - Eye-catching gradient title
- Subtitle: "Claim your Lionsun Coins. Help free the Roaring Lion."
- **Connect Wallet** button with hover effects

#### 2. Countdown Timer
- 🚀 **Real-time countdown** showing days, hours, minutes, seconds
- Styled timer units with glowing borders
- Updates every second automatically

#### 3. Wallet Connection
- **Connect Wallet** functionality (simulated)
- Wallet address display
- Connection status indicators

#### 4. Claim Zone
- 👛 **Wallet address** display
- 🎁 **150 $LIONSUN** reward amount
- ✅ **Eligibility status** chip
- **Claim Now** button (enabled after wallet connection)

#### 5. Referral System
- 🔗 **Referral link** with copy functionality
- 📋 **Copy button** for easy sharing
- 🎉 **Referral earnings** display (+50 $LIONSUN from 3 invites)

#### 6. Mini Lore Section
- 📖 **The Legend of Lionsun** story
- Styled quote box with cosmic theme
- Inspirational message about freeing the cosmic lion

## 🚀 How to Run

### Option 1: Standalone HTML Demo
```bash
# The demo is already running on port 8080
# Open your browser and go to:
http://localhost:8080/airdrop-demo.html
```

### Option 2: React Application
```bash
cd client
npm install
npm start
# Then open http://localhost:3000
```
